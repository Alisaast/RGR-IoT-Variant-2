
# Розрахунково-графічна робота
## Інформаційні технології Internet of Things
### Варіант № 2

**Тема практичної частини:** Моделювання IoT-системи моніторингу теплиці з використанням Edge Computing, SQLite та Firebase.

## Мета роботи
Розробити програмну модель IoT-системи для збору, очищення, зберігання та аналізу показників навколишнього середовища.

## Використані технології
- Python
- Google Colab
- SQLite
- Firebase Realtime Database
- Pandas, NumPy, Matplotlib
- gzip, zlib, bzip2

## Функціональні можливості
1. Генерація показників чотирьох типів сенсорів.
2. Моделювання шумів та пропущених значень.
3. Попереднє очищення даних на Edge-рівні.
4. Зберігання результатів у SQLite.
5. Статистичний аналіз показників теплиці.
6. Порівняння ефективності алгоритмів стиснення.
7. Передача даних до Firebase.
8. Зворотне завантаження даних у Google Colab.
9. Побудова графіків та статистичного звіту.

## Результати
- Кількість записів: 1095.
- Кількість ділянок: 3.
- Частка оптимальних значень pH: 96,35%.
- Кореляція температури та вологості ґрунту: -0,532.
- Найефективніший алгоритм стиснення: bzip2.
